Concessões rodoviárias: quem cumpre o que planeja?

Com os dados abertos da ANTT, este painel mede se as concessionárias de rodovias federais executam as obras no ritmo planejado, prevê quem tende a atrasar com machine learning e mostra os motivos e o impacto dos atrasos.

Como funciona

Um pipeline em Python que roda sozinho todo mês no GitHub Actions e atualiza este painel.

  1. ColetaBusca as bases na API de dados abertos da ANTT (CKAN), com plano B se o portal cair.
  2. Tratamento (ETL)Padroniza colunas, "55,7%", "1.234,56", datas e acentos com pandas.
  3. MétricasPrevisto × executado por mês e ano; tendência robusta (Theil-Sen + Kendall).
  4. Machine learningCompara regressão logística e gradient boosting (scikit-learn) e escolhe o melhor.
  5. SimulaçãoMonte Carlo com 5.000 cenários para o risco de cada concessionária.
  6. Testes e automaçãoTestes automatizados (pytest) e CI/CD no GitHub Actions; o painel é publicado no GitHub Pages.

  • Os dados são preenchidos pelas próprias concessionárias no sistema SIGICOR; nem todas as concessões estão lá e alguns campos vêm vazios.

  • Nos anos passados, o modelo só usa informações que existiam no mesmo ponto do ano; revisões feitas depois do atraso não entram.
